Your favicon set
================

Put every file in this archive in the ROOT folder of your website —
the same place as your home page — and paste the contents of
paste-into-your-head.html into the <head> of every page.

What each one is for:

  favicon.ico                The browser tab, and the file browsers ask for whether you link to it or not.
  favicon-96x96.png          Bookmarks and shortcut tiles on desktop browsers.
  apple-touch-icon.png       What an iPhone puts on the home screen. Opaque, because iOS turns transparency black.
  icon-192.png               Android home screens and the install prompt.
  icon-512.png               The large icon, used on splash screens and in app listings.
  icon-maskable-512.png      Android crops icons to whatever shape it likes, so this one is drawn smaller with room around it.
  site.webmanifest           Tells phones the name and colors to use when somebody installs your site.

A note on caching: browsers hold on to favicons stubbornly. If you are
replacing an old one and it looks unchanged, try a private window before
concluding something went wrong.

Made with the free favicon maker at meetpiggles.com/tools/favicon
